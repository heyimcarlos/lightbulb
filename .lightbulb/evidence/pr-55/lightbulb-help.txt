Commands:
  lightbulb completion          generate shell completion script
  lightbulb acp                 start ACP (Agent Client Protocol) server
  lightbulb mcp                 manage MCP (Model Context Protocol) servers
  lightbulb [project]           start opencode tui                                         [default]
  lightbulb attach <url>        attach to a running opencode server
  lightbulb run [message..]     run opencode with a message
  lightbulb debug               debugging and troubleshooting tools
  lightbulb providers           manage AI providers and credentials                  [aliases: auth]
  lightbulb agent               manage agents
  lightbulb upgrade [target]    upgrade opencode to the latest or a specific version
  lightbulb uninstall           uninstall opencode and remove all related files
  lightbulb serve               starts a headless opencode server
  lightbulb web                 start opencode server and open web interface
  lightbulb models [provider]   list all available models
  lightbulb stats               show token usage and cost statistics
  lightbulb export [sessionID]  export session data as JSON
  lightbulb import <file>       import session data from JSON file or URL
  lightbulb github              manage GitHub agent
  lightbulb pr <number>         fetch and checkout a GitHub PR branch, then run opencode
  lightbulb session             manage sessions
  lightbulb plugin <module>     install plugin and update config                     [aliases: plug]
  lightbulb db                  database tools
  lightbulb dashboard           show the Lightbulb account work graph

Positionals:
  project  path to start opencode in                                                        [string]

Options:
  -h, --help         show help                                                             [boolean]
  -v, --version      show version number                                                   [boolean]
      --print-logs   print logs to stderr                                                  [boolean]
      --log-level    log level                  [string] [choices: "DEBUG", "INFO", "WARN", "ERROR"]
      --pure         run without external plugins                                          [boolean]
      --port         port to listen on                                         [number] [default: 0]
      --hostname     hostname to listen on                           [string] [default: "127.0.0.1"]
      --mdns         enable mDNS service discovery (defaults hostname to 0.0.0.0)
                                                                          [boolean] [default: false]
      --mdns-domain  custom domain name for mDNS service (default: opencode.local)
                                                                [string] [default: "opencode.local"]
      --cors         additional domains to allow for CORS                      [array] [default: []]
  -m, --model        model to use in the format of provider/model                           [string]
  -c, --continue     continue the last session                                             [boolean]
  -s, --session      session id to continue                                                 [string]
      --fork         fork the session when continuing (use with --continue or --session)   [boolean]
      --prompt       prompt to use                                                          [string]
      --agent        agent to use                                                           [string]
