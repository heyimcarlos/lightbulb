PR 56: no-cron delegation automation

This PR adds request-driven Lightbulb delegation primitives without creating another recurring maintainer cron.

Changed surfaces

  • lightbulb-delegate skill: how parent agents dispatch isolated worker lanes.
  • lightbulb-loop-maintainer skill: how loop repairs are inspected and fixed without cron creep.
  • /delegate-async and /maintain-loops commands: entrypoints for request-driven automation.
  • lightbulb-orchestrator: defaults to async delegation before durable goal/Kanban/cron escalation.

Loop path

Request arrives
Parent loads Lightbulb skill
Async worker lanes run
Parent verifies evidence
Only scheduled triggers use cron
