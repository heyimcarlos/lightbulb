Slice 6: recurring loop schedules and budgets

Lightbulb now reads persisted loop-profile schedule and budget metadata as a deterministic scheduler read model. No provider/model call is required.

State flow

Loop profile metadata
schedule + budget
Scheduler classifier
due / not_due
Budget gate
held / open
Dashboard projection
next due + reason
Operator action
dispatch or hold

Observable behavior

  • due: next due time has passed and budget is open.
  • not_due: next due time is in the future or missing.
  • disabled: loop or schedule is disabled.
  • budget_held: explicit budget hold or daily run count exhausted.

Focused package-local tests, typecheck, migration check, and whitespace checks passed from packages/core. See verification.md.
