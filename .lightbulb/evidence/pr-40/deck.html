PR #40: Lightbulb Subagents

Adds six project-scoped OpenCode subagents so Lightbulb can route codebase, thoughts, and web-research questions to focused read/search-only agents.

What changed

codebase-locator
Finds relevant code files without analysis.

codebase-analyzer
Explains current implementation with file:line references.

codebase-pattern-finder
Catalogs existing implementation/test patterns.

thoughts-locator
Finds relevant thoughts documents.

thoughts-analyzer
Extracts high-value decisions and constraints.

web-search-researcher
Researches current web sources with citations.

Safety boundary

  • All six agents use mode: subagent.
  • Frontmatter denies * first, then allows only read/search/web/todo permissions required for the role.
  • No edit, bash, PR, issue, or merge authority is granted by these agent files.
