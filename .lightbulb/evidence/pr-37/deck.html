Account loop profile bootstrap

Issue #31 adds a core Lightbulb seam that creates or adopts the standard account loops for a durable goal without launching a live model or worker.

Control-plane behavior

  • Stable loop IDs are derived from goal ID + profile ID.
  • Bootstrap is idempotent: retry adopts existing profile loops.
  • Disabled, budget-held, missing-goal, custom-policy, and invalid-profile outcomes return bounded reasons.
  • Custom operator schedules are preserved instead of overwritten.
