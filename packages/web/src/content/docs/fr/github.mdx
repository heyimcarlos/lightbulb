---
title: GitHub
description: GitHub Action integration is disabled in Lightbulb.
---

Lightbulb intentionally disables the inherited OpenCode GitHub Action and installer.

The upstream action installs and runs upstream OpenCode surfaces that do not match Lightbulb's current release channel, GitHub App identity, trigger vocabulary, or installer path. Do not use `opencode github install`, `/opencode`, or `/oc` to set up Lightbulb automation.

A Lightbulb-native GitHub Action needs a separate design for release channels, token exchange, trigger phrases, and verification before this page can provide setup steps.
