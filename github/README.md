# Lightbulb GitHub Action

The inherited GitHub Action is intentionally disabled in Lightbulb.

Lightbulb does not yet have a supported GitHub Action release channel, trigger vocabulary, GitHub App, or installer path. `github/action.yml` and `opencode github install` fail fast so workflows cannot accidentally install or run upstream OpenCode.

Re-enable this package only after a Lightbulb-native action is designed and verified.
